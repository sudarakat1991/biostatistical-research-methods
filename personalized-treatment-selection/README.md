# Personalized Treatment Selection Using Observational Data

This directory shares original R research code associated with the **population-based observational study of statin use** application in *Personalized Treatment Selection Using Observational Data*.

Only the statin application is included. This is not a release of all simulations or a complete software package for the publication.

See [statin-application/README.md](statin-application/README.md) for the code inventory, dependencies, data source, and execution notes.
